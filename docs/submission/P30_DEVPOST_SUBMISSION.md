## 3. The Problem: Why Green CI Lies

AI coding agents (Copilot, Cursor, Codex, and custom autonomous agents) write and edit software at staggering velocity. To evaluate them, developers and benchmarks rely almost entirely on Continuous Integration: *if the test suite turns green, the change is accepted.*

**This assumption is fundamentally broken.** Green CI cannot prove causation:
1. **Pre-Existing Passing Tests**: Many tests pass before the agent touches the code because the test never exercised the edge case or assertion. The AI patch might do nothing—or introduce subtle regressions—while CI celebrates a false victory.
2. **Vacuous Assertions**: Large language models frequently solve test suites by modifying test files, weakening assertions, or mocking out components rather than implementing genuine behavioral repairs.
3. **Overfitted Patches**: A patch may pass a synthetic test without addressing the underlying invariant required by the system.

In software engineering, testing a candidate in isolation is insufficient. **If the patch matters, the base must break.**

---

## 4. The Solution: Basebreak's Three-World Causal Engine

Basebreak is an empirical verification runtime for AI-written code. Instead of trusting green tests, Basebreak evaluates an engineering change across three isolated execution worlds orchestrated inside **Nebius Token Factory Sandboxes**:

```
[World 1: BASE]           --> Run Sealed Witness --> FAIL (Exit 1)  [Defect is reproduced]
[World 2: CANDIDATE]      --> Run Sealed Witness --> PASS (Exit 0)  [Defect is fixed]
[World 3: COUNTERFACTUAL] --> Run Sealed Witness --> FAIL (Exit 1)  [Patch was necessary]
```

To achieve an overall verdict of **`VERIFIED`**, the run must strictly satisfy the **Causal Triplet**:
$$\text{BASE} = \text{FAIL} \quad \land \quad \text{CANDIDATE} = \text{PASS} \quad \land \quad \text{COUNTERFACTUAL} = \text{FAIL}$$

If the base does not fail, the witness did not exercise the bug. If the candidate does not pass, the patch did not fix it. And if reverting the patch in the counterfactual world does not fail, the patch was causally irrelevant to the outcome.

## 5. How We Built It: Architecture & Technical Implementation

Basebreak is engineered from the ground up to guarantee strict isolation, deterministic fact authority, and zero-friction inspection:

1. **AI Model Generation on Nebius Token Factory**:
   - Uses `nvidia/Nemotron-3_5-Lightning` hosted natively on Nebius Token Factory.
   - Candidate generation proposals are ingested and analyzed via **pure static AST inspection** (`ast.parse`) in Python 3.13. Untrusted candidate code is never compiled, evaluated, imported, or executed on the host.
2. **Multi-World Nebius Sandboxes**:
   - Differential execution is executed across eleven discrete operations inside clean, isolated Nebius microVM sandboxes.
   - Each world materializes a fresh, immutable tree derived from the base commit (`80b43b84...`), isolating filesystem and network state.
3. **Cryptographic Fact Authority & Signing**:
   - The trusted verification bridge derives SHA-256 digests of all inputs, outputs, candidate git trees, and stderr/stdout logs.
   - Every completed run is authenticated with an **RSA-2048 cryptographic proof** generated by an isolated verifier signer.
4. **Cloudflare Workers & SQLite Durable Object Ledger**:
   - Hosted globally on Cloudflare Workers Free Tier (`https://basebreak.zyganali.workers.dev`).
   - Run receipts are committed to an immutable append-only SQLite Durable Object ledger.
   - Hackathon judges can inspect the full causal receipt, witness execution commands, and telemetry **completely signed-out with zero login friction**.
5. **Zero Personal Spend & Strict Financial Governance**:
   - Development and judging operate strictly under the **Zero-Cost Law**: target personal spend is **$0.00**.
   - Public endpoints are strictly read-only; no unmetered live execution endpoints exist that could drain promotional credits.

## 6. Meaningful External Grounding: Best Use of Tavily ($3,000 Bonus)

Basebreak does not use search as decorative bonus theater. For tasks where code correctness materially depends on current external reality (e.g. `CVE-2024-21626` container escape security advisories or library API migrations), Basebreak integrates a bounded, deterministic Tavily Search adapter (`src/basebreak/adapters/tavily/`):

- **Tavily Grounds WHAT Must Be Verified**:
  Tavily queries official advisory registries (NIST NVD, GitHub Security Advisories) to retrieve authoritative vulnerability mechanisms (`file descriptor leakage`) and affected/fixed version numbers (`<=1.1.11` vs `1.1.12`).
- **Sandboxes Verify WHETHER Code Satisfies It**:
  Nebius sandboxes and Nemotron execute the candidate against the sealed witness.
- **Deterministic Authority Firewall (`firewall.py`)**:
  External web search results **NEVER override code execution**. Even if Tavily returns an authoritative advisory stating that a vulnerability is patched, if the sandbox candidate fails, the firewall strictly outputs `PreliminaryVerdict.CONTRADICTED`.
- **Security & Integrity**:
  The Tavily client enforces bounded query validation, blocks credential and sealed witness token leakage, strips HTML/LLM answers, and strictly fails closed on adversarial prompt injection payloads (`INJECTION_BLOCKED`).

## 8. Limitations & Honest Engineering Boundary

- **Empirical Causal Verification, Not Global Proof**: Basebreak provides empirical causal proof under the specified sealed witness. It proves the patch caused the observed state transition under that test; it does not claim formal mathematical correctness across all possible unstated inputs.
- **Witness Scope**: The live demonstration verifies one sealed behavioral witness (`wit-reset-vault-live-001`) under the canonical `ResetVault` scenario.
- **Signature Scheme**: The verifier signature uses custom 2048-bit raw modular exponentiation RSA over SHA-256 digests. It is independently verifiable across Python and Node.js, but is not standard PKCS#1 v1.5 or RSA-PSS.
- **Model Candidate Scope**: In live runs, candidate code is generated by `nvidia/Nemotron-3_5-Lightning` in one shot; multi-turn repair loops are implemented and tested offline.
