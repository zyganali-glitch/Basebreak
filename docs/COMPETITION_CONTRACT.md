# Competition Contract — Nebius x NVIDIA Global AI Hackathon

Snapshot date: 2026-09-12.
Authoritative source at submission time remains the official Devpost rules.

## Current verified essentials
- Submission deadline: 2026-10-30 10:00 PDT.
- Primary track: Coding and Agentic Engineering.
- Track wording requires coding agents/developer tools that write, run and test code in Token Factory Sandboxes.
- Project must run on Nebius Token Factory or Nebius AI Cloud and use at least one NVIDIA open-source model.
- Runtime inference call to Token Factory qualifies as running on Token Factory; Nebius AI Cloud compute may also qualify under the official rule wording.
- Public repository required.
- Open-source license required and should be visible on the repository page.
- README/setup guidance required.
- Working demo/test build URL required.
- Public YouTube demo must be <3 minutes.
- Submission materials must be English or include English translation.
- Stage One rejects superficial rebrands.
- Stage Two criteria are equally weighted:
  1. Technological Implementation
  2. Design
  3. Potential Impact
  4. Quality of Idea
- Best Use of Tavily requires a functional runtime Tavily API call as part of the solution.

## Basebreak compliance posture
Basebreak is newly created during the submission period.
Donor repos are inspiration/provenance sources, not the implementation base.
Nebius/NVIDIA use must be essential to the demonstrated runtime, not decorative.

## Required pre-submit revalidation
Before release freeze, re-check:
- dates/deadline;
- track wording;
- model/runtime eligibility;
- license visibility;
- demo and repository requirements;
- bonus rules;
- judge criteria.
